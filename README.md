# Projects

A collection of frontend and full-stack projects built while learning web development, ranging from vanilla JS games to a full-stack authentication app.

## Projects

### LoginSystem — Full-Stack Auth App
A complete login/registration system with a separate frontend and backend.
- **Frontend:** React, Material UI (MUI), axios, React Router
- **Backend:** Node.js, Express, CORS — REST endpoints with a JSON file as the data store
> Note: a learning demo — user data is stored in a local JSON file with plaintext passwords. A production version would hash passwords and use a database.

### LoginRegister — React Auth UI
A login and registration interface built with React and react-icons.

### Drum Kit
An interactive drum machine — keys **Q–U** (and clicks) trigger real drum samples (kick, snare, toms, crash).
Tech: HTML · CSS · JavaScript

### Dicee Challenge
A two-player dice game — roll and the higher number wins.
Tech: HTML · CSS · JavaScript

## Tech Stack
React · Material UI · Node.js · Express · JavaScript · HTML · CSS

## Running a project
React apps (LoginSystem, LoginRegister): `npm install` then `npm start`.
Vanilla JS apps (Drum Kit, Dicee): open `index.html` in a browser.
